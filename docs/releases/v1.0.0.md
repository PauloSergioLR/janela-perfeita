# Janela Perfeita v1.0.0

Primeira versão pública estável do Janela Perfeita.

## Destaques

- cockpit climático orientado à decisão;
- recomendação da melhor janela para atividades;
- score explicável de 0 a 100;
- confiança e motivos da recomendação;
- modos Janela perfeita, O que fazer hoje?, Consulta do dia e Consulta da semana;
- timeline horária navegável;
- comparação dos próximos dias;
- localização atual opcional;
- tema claro e escuro;
- modo de demonstração;
- PWA;
- documentação técnica e fluxogramas;
- suíte automatizada com Vitest, Playwright e GitHub Actions.

## Dados climáticos

A aplicação utiliza Open-Meteo como fonte climática e
OpenStreetMap/Nominatim apenas para geocodificação reversa opcional.

## Observação

As recomendações são estimadas e não substituem alertas meteorológicos oficiais
nem avaliação das condições locais.
